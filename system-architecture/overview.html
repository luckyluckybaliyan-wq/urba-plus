Diagram 04
Duplicate Detection Algorithm
Haversine spatial filter + Gemini visual scoring. Score ≥ 75 merges as duplicate.
flowchart TD NR([New Report Submitted]) --> HD[Haversine Distance Filter\nCandidates within 250m] HD -->|No candidates| NEW[✅ New Issue\nSave to Firestore] HD -->|Candidates found| GS[Gemini Visual + Text Scoring\nper candidate] GS --> SC[Calculate Overall Score\nLocation 40% + Image 35%\nText 20% + Time 5%] SC -->|Score ≥ 75| DUP[🔁 DUPLICATE FOUND\nShow modal to citizen] SC -->|Score < 75| NEW DUP -->|Citizen confirms| MERGE[Merge as Supporter\nIncrement supportersCount] DUP -->|Citizen ignores| NEW
Diagram 05
AI Resolution Verification
Authority records on-site video. Gemini compares before photo vs after frames. 80% confidence required.
sequenceDiagram participant A as 👷 Authority participant B as Browser participant API as /api/verify-resolution participant G as Gemini AI participant FS as Firestore participant E as 📬 Citizen Email A->>B: Record 30s geotagged video B->>API: POST beforeImage + videoFrames[] + GPS coords Note over API: Requires ≥ 4 frames API->>G: Compare before photo vs after frames G-->>API: confidence score + findings alt Confidence ≥ 80% API-->>B: verificationPassed = true B->>FS: status → Resolved ✅ B->>E: Send resolution email to citizen else Confidence < 80% API-->>B: verificationPassed = false B->>FS: status → Resolution Failed ❌ B->>E: Send re-work notification to citizen end
